# 💕 Para Ti - Mensaje Romántico Digital

Una hermosa página web romántica interactiva hecha con HTML, CSS y JavaScript puro.

## 🎨 Características

✨ **Diseño Elegante y Emotivo**
- Paleta de colores romántica (rosados, lilas, degradados elegantes)
- Tipografías delicadas y cursivas
- Animaciones suaves y modernas

💖 **Interactividad**
- Botón "Presiona Aquí" que revela mensajes especiales
- Botón "Crea Magia" que genera lluvia de corazones
- Efectos especiales en clicks
- Sonidos suaves (Web Audio API)

🌟 **Animaciones**
- Corazones flotantes animados
- Estrellas parpadeantes de fondo
- Efectos de brillo radiante
- Confeti romántico
- Transiciones suaves

📱 **Responsive**
- Funciona perfectamente en móvil, tablet y desktop
- Diseño adaptable a cualquier pantalla

## 🚀 Cómo Usar

1. **Localmente:** Solo abre el archivo `index.html` en tu navegador
2. **Online:** Copia el link y comparte por WhatsApp, email, redes sociales, etc.

## 🧠 Tecnología

- **HTML5** - Estructura semántica
- **CSS3** - Animaciones y estilos
- **Vanilla JavaScript** - Sin frameworks externos
- **Web Audio API** - Efectos de sonido
